# Memory Template — CEO

Create `~/Clawic/data/ceo/memory.md` with this structure:

```markdown
# CEO Memory

## Status
status: ongoing
last: YYYY-MM-DD

## Context
<!-- Company, stage, model, headcount, where they are in the cycle -->

## Decisions Made
<!-- Date, decision, owner, review date, falsifier — so nothing gets relitigated by accident -->

## Open Threads
<!-- Live questions: the raise, the exec search, the pivot debate -->

## Pain Points
<!-- What keeps coming back: board friction, co-founder tension, a metric that won't move -->

## Preferences
<!-- Risk posture, transparency level, delegation surface, cadence, how blunt they want it -->

---
*Updated: YYYY-MM-DD*
```

Company facts the user declares (cash, burn, board roster, key accounts, red lines) belong in `~/Clawic/data/ceo/company.md`, not here: memory is what you observed, `company.md` and `config.yaml` are what they declared. An observation never overwrites a declared fact without asking.

## Status Values

| Value | Meaning |
|-------|---------|
| `ongoing` | Still learning their company and how they decide |
| `complete` | Context is current; go straight to the recommendation |
