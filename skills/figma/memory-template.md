# Memory Template — Figma

Create `~/Clawic/data/figma/memory.md` with this structure:

```markdown
# Figma Memory

## Status
status: ongoing
last: YYYY-MM-DD

## Context
<!-- Their file and library structure: how many files, which libraries, who publishes -->
<!-- Design system maturity: styles, variables, or mid-migration -->
<!-- Who consumes the handoff: engineers, agency, an agent pipeline -->

## Pain Points
<!-- Issues they've raised: slow files, broken library updates, handoff churn -->

## Preferences
<!-- Annotation depth, tokens-first vs screens-first, confirm-before-destructive -->
<!-- Integrations the handoff must feed -->

---
*Updated: YYYY-MM-DD*
```

## Status Values

| Value | Meaning |
|-------|---------|
| `ongoing` | Still learning their file and system setup |
| `complete` | Know their structure and handoff well |
