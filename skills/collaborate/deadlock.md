# Deadlock — When the Exchange Stops Moving

Trigger: 2 consecutive rounds with zero position movement (SKILL.md Rule 6), or the parties restate the same points with rising temperature. More rounds from here add heat, not information. Diagnose the gap type first; each type has a different exit.

## Diagnose the Gap

Ask both sides: "what evidence would change your mind?" Then read the symptom:

| Symptom | Gap type | Exit |
|---|---|---|
| Neither side can name mind-changing evidence | Values or incentives | Owner decides; dissent recorded — no experiment settles values |
| Both name evidence, nobody has it | Information | Stop arguing; go get the evidence or run the cheapest test |
| Agreement on facts, disagreement on action | Different loss functions | Make both loss functions explicit; decision owner weighs them |
| Disagreement on the facts themselves | Data conflict | Trace both claims to sources; one of you is citing memory |
| New arguments every round, zero movement | Motivated reasoning (either side) | Crux isolation, below — or stop, the position is not evidence-based |

## Moves Before Stopping

- **Crux isolation** (double crux, CFAR): search for the single claim where you disagree AND both agree that flipping it would flip the decision. Most deadlocked threads disagree on many decorative points and one crux; arguing anything but the crux is noise.
- **Bet framing.** "What odds would you put on X?" Converts posture into numbers; a party who argues certainty but bets 60/40 has told you their real position.
- **Decompose the decision.** Split into the part you agree on (ship it) and the part you do not (shrink the disagreement to its minimal core; often it no longer blocks).
- **Time-boxed experiment.** Replace round 3 with a test: cheapest observable that discriminates between positions, deadline attached. An experiment both sides pre-commit to interpret is worth more than any rhetorical win.

## Disagree-and-Commit

Applies when a decision owner exists and the gap is values/incentives:

1. The owner decides; the dissenter's objection goes in the decision record verbatim, with a revisit trigger (`convergence.md`).
2. The dissenter executes at full effort. Sandbagging test: would an observer watching only your execution guess you had objected? If yes, you did not commit.
3. Recorded dissent is the dissenter's protection AND the system's memory — if the trigger fires, the record reopens the question without "I told you so" archaeology.

## Escalation

Only if the deadlock blocks work; unblocked disagreements just get recorded.

- Escalate the crux question, not the thread. The escalation brief: one paragraph per side — written jointly, each side signs off on the other's paragraph — plus the crux and what each answer implies. A jointly-written brief prevents the race to frame first.
- Escalate to whoever owns the consequence, not whoever is most senior (the user's stated escalation path overrides — Configuration preference areas).
- One escalation per disagreement. Shopping for a second adjudicator after losing the first converts a decision system into politics.

## Recording the Unresolved

A deadlock that stops without a decision still produces a record (`decision-log.md`): both positions, the crux, why it stopped (not blocking / awaiting evidence), and what evidence or event reopens it. Unrecorded deadlocks are re-fought from scratch by the next person — the record is the only asset a failed exchange produces, so never skip it.
