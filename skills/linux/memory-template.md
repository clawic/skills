# Memory Template — Linux

Create `~/Clawic/data/linux/memory.md` with this structure:

```markdown
# Linux Memory

## Status
status: ongoing
last: YYYY-MM-DD

## Hosts
<!-- Role, distribution and version, cloud or bare metal, how they reach it -->

## Recurring Incidents
<!-- What breaks repeatedly on their systems and what fixed it -->

## Environment
<!-- Tools actually installed, config management in use, monitoring stack -->

## Preferences
<!-- Explanation depth, dry-run habits, change windows, restrictions -->

---
*Updated: YYYY-MM-DD*
```

## Status Values

| Value | Meaning |
|-------|---------|
| `ongoing` | Still learning their environment |
| `complete` | Know their hosts and habits well |
