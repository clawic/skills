# Assessment — Baselines, Testing, Starting Loads

What to establish before prescribing, and how to re-test without burning training time. Collect inside normal work — from the log, from what the user volunteers — never as a questionnaire.

## Minimum Baseline Set

| Baseline | How | Used by |
|---|---|---|
| e1RM per main lift | Epley from any hard 3-8 rep set (SKILL.md Rule 2) | Every load prescription |
| Resting HR | 7-morning average, same conditions (on waking, before coffee) | Readiness check, deload trigger (Rule 7) |
| Attendance rate | Sessions done / planned, last 4 weeks, from `log.md` | Split selection (SKILL.md Program Design Defaults) |
| Cardio benchmark | Distance covered in a 12-min steady hard effort (Cooper-style field test), or any repeatable route + time | Endurance progress checks |
| Movement screen | Pain-free bodyweight squat, hinge, push-up, row | Gates loading; a painful pattern routes to substitutions, persistent pain to Red Flags |

## Starting Loads With No Log

Never guess a working weight from bodyweight or demographics. Find it live:

1. Ramp: empty bar or light dumbbell x 10, then add load in 3-4 jumps of decreasing size, 3-5 reps each.
2. Stop at the first load where 8 reps would end at RIR 3 by the user's report. That is the working weight.
3. Log it. Next session runs beginner progression (+2.5 kg upper / +5 kg lower, SKILL.md Progression) — the first weeks self-correct any misjudgment, so err low: a start 10% too light costs one week; 10% too heavy costs form and confidence.
4. Technique gate: if form breaks before RIR 3, the working weight is the last clean load, regardless of effort.

## e1RM Percentage Table (Epley-derived)

%1RM = 1 / (1 + reps/30). Same formula as Rule 2, inverted — use one table everywhere.

| Reps | %e1RM |
|---|---|
| 3 | 91% |
| 5 | 86% |
| 8 | 79% |
| 10 | 75% |
| 12 | 71% |

Read it both ways. To prescribe a load, a rep target maps to %e1RM — all rows valid. To estimate e1RM from a set you performed, use only 3-8 rep sets taken to RIR 0-2 (SKILL.md Rule 2): above ~10 reps the estimate drifts and varies by lift (squats overperform the table, presses track it), so a 20-rep set predicts nothing useful.

## Cardio Baselines

- Talk test calibrates before any HR math: full sentences = easy, phrases = threshold-ish, words = hard. It self-adjusts for heat, fatigue, and caffeine — HR does not.
- HR zones only after resting HR is a real 7-morning average and HRmax is either measured (`measured_hrmax`) or Tanaka-estimated (Rule 5). One morning's reading is noise.
- Field test cadence: repeat the same benchmark (route, machine, protocol) every 6-8 weeks. Changing the test resets the trend.

## Re-Testing Cadence

- e1RM: recompute continuously from logged top sets — free, no test day needed. Planned true-1RM attempts only in a peak week (Rule 2).
- Bodyweight: daily if the user weighs anyway, compared as weekly averages; never react to one day.
- Resting HR baseline: rolling; re-anchor after illness or a time-zone change, both inflate it for days.
- Movement screen: re-run only after injury or a 4+ week layoff.

## Classifying Training Age

Labels change the progression model, so classify by observed response, not self-report — most people under-rate or over-rate themselves:

- **Beginner**: adds load every session without stalling. Stay on session-to-session progression until the first genuine stall.
- **Intermediate**: progresses week to week via double progression (Rule 1). Most trainees, most of the time.
- **Advanced**: months between PRs despite clean inputs. Block structures and specialization become worth their complexity.
