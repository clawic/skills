# Progression — Models and Plateau Playbooks

When to use which progression scheme, and symptom-first chains for when progress stops. The canonical numbers live in SKILL.md: double progression increments (Rule 1), beginner per-session adds and the stall definition (Progression and Plateaus), deload protocol (Rule 7).

## Which Model When

| Trainee state | Model | Graduate when |
|---|---|---|
| Beginner (adds load every session) | Linear: +2.5 kg upper / +5 kg lower per session | First stall survives the diagnostic order below |
| Intermediate | Double progression (Rule 1) | Months pass between rep-range completions despite clean inputs |
| Advanced | Block: 3-5 weeks accumulation (volume up, RIR 2-3) → 1-3 weeks intensification (volume down, load up, RIR 1-2) → deload | — |
| Peaking for a dated event | Intensification block ending ~1 week out, deload into the date, 1RM attempts only here (Rule 2) | — |

Complexity is a cost: move down this table only when the simpler model demonstrably stopped working (SKILL.md, Where Experts Disagree). Block lengths stay inside the Rule 7 cap of 4-8 hard weeks.

## Autoregulation Within a Session

- Daily readiness moves loads ±5%, never the plan. First work set feels like RIR 1 when RIR 3 was prescribed → drop 5% for today, log it, keep the program.
- The reverse too: prescribed load feels like RIR 4+ → finish as prescribed, log the extra reps; double progression converts them next session. Never jump load mid-session on a good day — that steals next week's progression.
- Readiness check itself (HR/sleep/appetite) is canonical in SKILL.md Recovery and Readiness.

## Plateau Playbooks (symptom → cause)

Run SKILL.md's diagnostic order first (log audit → inputs → deload+90% → one change). These chains localize the cause by pattern:

**One lift stalled, everything else moving**

1. Technique ceiling, not a strength ceiling — most common on overhead press and pull-up, where the smallest plate is a big % jump.
2. Microload: 1.25 kg increments, or +1 rep on one set only.
3. Still stuck after 3 more sessions: variant swap targeting the weak range — failed at the chest on bench → pause bench; failed at lockout → close grip. The variant holds 4-6 weeks, then re-test the main lift.

**All lifts stalled together**

1. Recovery-side, not program-side: audit sleep average (under 7h explains most stalls — SKILL.md), calorie deficit, life stress in that order.
2. Inputs clean → Rule 7 deload, resume at 90% of stall loads.
3. Stalls again within 3 weeks → volume is above the user's current ceiling: cut weekly sets by ~25% toward the Rule 4 floor and hold there 4 weeks. More volume is the intuitive move and the wrong one (SKILL.md Traps).

**Reps falling at loads that used to be routine**

- Performance regressing, not plateauing: acute fatigue or an unlogged gap. Check `log.md` for missed sessions (Rule 6 applies), then resting HR trend (Rule 7 trigger), then illness onset. Never chase falling reps with added load.

**Endurance pace stalled**

- First suspect: easy days drifted hard, hard days drifted easy — re-audit the 80/20 minute split with real HR or talk-test data before adding volume (SKILL.md Rule 5, gray-zone trap).

**Scale stalled**: the lift log decides the lever — lifts strong + scale flat = intake side; lifts fading = recovery first.

## Rep-Range Shifts

When double progression at 8-12 stalls twice (post-deload), shift the range, keep the exercise: 8-12 → 4-6 for a strength block (load jumps ~10-15% by the Epley %e1RM relation, Rule 2), or 8-12 → 12-20 on isolation where joints complain. Run the new range 4-6 weeks, return, and re-enter double progression at the old stall load minus 5% — it moves again more often than not.

## Progression Hygiene

- One change at a time (canonical, SKILL.md) — microload OR range shift OR variant, never bundled, or the working change is unidentifiable.
- Every model change gets a log annotation with date and reason; unannotated changes make later diagnosis archaeology.
- PRs are lagging indicators: judge a change after 3 weeks of trend, not one good day.
