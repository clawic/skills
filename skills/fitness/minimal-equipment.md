# Minimal Equipment — Home, Travel, Time-Crunched

Keeping the program alive when the gym, the gear, or the hour is missing. Pattern substitutions route through SKILL.md's Quick Reference; maintenance doses are canonical in SKILL.md (one heavy full-body session per week maintains strength; cardio needs two short sessions).

## Loading Without Load

When the heaviest available implement is too light, add difficulty instead of weight — in rough order of load added:

1. **Tempo**: 3-second lowering + 1-second pause at the hard point. Turns a 20-rep push-up into an 8-rep set.
2. **Range**: deficit push-ups on books, heels-elevated squats — longer range, harder rep.
3. **Unilateral**: one limb doubles the effective load — split squat → rear-foot-elevated → pistol progression; single-leg RDL; archer push-up.
4. **Mechanical drop within the set**: hardest variant to near-failure, continue with an easier one (pike push-up → push-up).
5. **Bands**: the cheapest strength-curve fix for pulls, which bodyweight covers worst — a door-anchor band restores pulldowns and rows.

High-rep license: loads down to ~30% of 1RM build comparable muscle when sets approach failure (Schoenfeld low-load work) — so a 25-rep goblet squat at RIR 1 is a legitimate hard set (Rule 4 counts it). The cost is strength specificity: heavy-lift numbers need heavy practice, so shift expectations to rep PRs while equipment is capped (count sets as e1RM inputs only up to 8 reps, Rule 2 — beyond that, track rep PRs directly).

## Bodyweight Progression Ladders

Move one rung when the top of a 10-20 rep range is reached at RIR 1-2 — same double-progression logic as Rule 1, with rungs instead of plates:

- **Push**: wall → incline → knee → full → deficit → feet-elevated → pseudo-planche/pike lineage
- **Squat**: box squat → full → split squat → rear-foot-elevated → step-up (high box) → assisted pistol → pistol
- **Hinge**: glute bridge → hip thrust (feet elevated) → single-leg hip thrust → single-leg RDL (loaded with anything) → nordic regressions
- **Pull**: doorframe row (steep) → table/inverted row → feet-elevated row → chin-up negatives → chin-up → pull-up ladder

## Dumbbell-Only Template (pairs up to ~2x25 kg)

Full-body x3 (per `training_days` default), A/B alternating: goblet or DB split squat · DB floor/bench press · single-arm row · DB RDL · carry or isolation finisher. All Rule 8 formatting and Rule 1 progression apply unchanged; when the top range at max dumbbell is reached, apply the loading list above instead of buying hope.

## Travel Week

- Maintenance target, canonical: one heavy full-body session + two short cardio sessions holds the line for a week or two.
- Hotel-room session (no equipment, ~25 min): ladder push-up variant 3 sets · split-squat variant 3 sets · inverted row under any desk/towel-door or backpack row 3 sets · single-leg hip thrust 2 sets · all RIR 1-2, minimal rest between alternating upper/lower.
- Cardio: 2 × 20-30 min — runs, hotel bike, or brisk hill walks all count (Zone 2 modality is fungible).
- Longer than 2 weeks away is no longer travel — it's a program: rebuild a full plan from whatever `equipment` reality allows, and apply Rule 6 to any lifts that couldn't be trained at all.

## Time-Crunched Sessions

`session_minutes` under 40 triggers these; cutting rest on heavy compounds is the one forbidden move (canonical rest rule, SKILL.md).

- **Cut in priority order**: isolation first, then assistance sets, then cardio appendix. The first heavy compound of the day is untouchable.
- **Antagonist supersets**: push/pull pairs share rest productively — bench + row at 2 min between alternating sets keeps both lifts near full output in half the time.
- **Rest-pause on isolation**: one load, set to RIR 1, 15-20s rest, repeat to ~half the reps, twice — a 3-set stimulus in 3 minutes. Isolation only; rest-pause on heavy compounds degrades form.
- **20-min floor session**: one compound pair supersetted 4 rounds + one isolation rest-pause. Two of these beat one perfect skipped session — attendance math (SKILL.md Traps) applies to session length too.
- EMOM/circuit formats are fine for conditioning; they are cardio in disguise, so log them as cardio minutes, not as hard sets.
