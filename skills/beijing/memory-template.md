# Memory Template — Beijing

Create `~/Clawic/data/beijing/memory.md` with this structure:

```markdown
# Beijing Memory

## Status
status: ongoing
last: YYYY-MM-DD

## Context
<!-- Role and stage: visiting (dates), relocating, settled resident, leaving -->
<!-- Home base district, workplace/school area, visa type -->

## Family
<!-- Partner, kids and schools, ayi arrangement, pets -->

## Concerns
<!-- Recurring topics: AQI sensitivity, commute pain, renewal deadlines -->

## Preferences
<!-- Observed (not declared) leanings: food adventurousness, pace, transport habits -->

---
*Updated: YYYY-MM-DD*
```

## Status Values

| Value | Meaning |
|-------|---------|
| `ongoing` | Still learning their situation |
| `complete` | Know their setup well |

Declared preferences belong in `config.yaml`, not here — an observation never overwrites a declared preference without the user confirming.
