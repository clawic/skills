# Memory Template — Design

Create `~/Clawic/data/design/memory.md` with this structure:

```markdown
# Design Memory

## Status
status: ongoing
last: YYYY-MM-DD

## Context
<!-- Their projects and typical artifacts (product UI, decks, social, print) -->
<!-- Tools and delivery format (HTML/CSS, Figma specs, rendered images) -->

## Brand and Register
<!-- Aesthetic leanings observed: minimal/dense/editorial/playful -->
<!-- Brand constraints mentioned outside brand.md -->

## Recurring Feedback
<!-- Corrections they repeat ("less decoration", "bigger type") -->

## Preferences
<!-- Critique style: punch-list vs walkthrough -->
<!-- Motion posture, platform targets, language/script needs -->

---
*Updated: YYYY-MM-DD*
```

## Status Values

| Value | Meaning |
|-------|---------|
| `ongoing` | Still learning their taste and context |
| `complete` | Know their register and workflow well |
