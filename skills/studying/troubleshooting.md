# Troubleshooting — Symptom to Cause

Work symptom-first; each chain is ordered by probability, and every step is a check against logs, not a guess. Per-question misses classify via SKILL.md Diagnosing Misses; this file covers session-level, plan-level, and student-level failures.

## "I studied hard and forgot everything"

1. Check the Session Log in memory.md: pages read but no questions answered → the sessions were re-exposure; rebuild on Rule 1.
2. Questions answered but massed into 1-2 days → spacing failure; redistribute per Rule 2.
3. Retrieval and spacing both present → check HOW it was forgotten: recognized instantly on reveal = gaps too long, halve them; no memory of ever seeing it = never encoded — distracted first contact (`focus.md`), requeue as new material.
4. Forgotten only under exam conditions → format mismatch or anxiety (`test-day.md`).

## Practice scores plateau

1. Error log by type (`problem-subjects.md`): the same error type recurring → apply that type's targeted fix, not more volume.
2. Errors scattered and careless → pacing (apply per-question budgets) or fatigue (check session length against the logged degradation point, Session Protocol 5).
3. Clean errors but the score stays below target → prerequisite gap; the missing layer is usually one course back — test it directly instead of grinding the current level.

## Always behind the plan

1. Plan overbooked → re-plan at two-thirds of the topics-per-slot the failed plan assumed; grow only after a full week executes. Planned volume is a hypothesis the log tests.
2. Slots collide with real life → re-anchor the week (`scheduling.md`): fixed obligations first, study in what remains — never the reverse.
3. Slots exist but never start → an entry problem, not a scheduling problem (`focus.md`).

## Flashcard reviews ballooning

1. Daily queue past `daily_review_cap` → stop new cards (`memorization.md` throttle).
2. The same items failing repeatedly → already flagged twice under Session Protocol 3 → rewrite the card smaller or add a contrast card; grinding an ill-formed item wastes the whole queue's time.
3. Deck built by copying someone else's cards → cards the student didn't generate carry no encoding; regenerate the failing ones from their own misses.

## "Understands in class, fails alone"

- Scaffolding illusion: the lecturer's sequencing did the method-selection work. Fix: same-day solo re-derivation of whatever was "understood" in class; the first solo attempt is the diagnosis, not the review.

## Falls asleep or zones out while reading

1. Passive input in a low-energy slot → move production tasks (problems, recall writing) into that slot; reading moves to a fresher one.
2. Happens in every slot → sleep debt: studying is competing with the consolidation it depends on (Rule 6). Fix sleep before technique.

## Motivation collapse mid-plan

1. Outcome too distant → process goals plus a visible streak (`focus.md`).
2. Adherence intact but output declining → burnout markers (`focus.md`): cut session count, keep the Rule 1 and Rule 6 floors.
3. Aversion to one course only → usually a prerequisite gap making every session a wall; diagnose the gap, not the attitude.

## Exam scores below practice scores

1. Practice conditions were softer (open notes, untimed, retries) → exam conditions from the first practice test onward (SKILL.md Traps).
2. Conditions matched → exam-day execution: pacing, parking, blanking (`test-day.md`).
3. Recurring panic symptoms → SKILL.md Red Flags: route to counseling before more optimization.

## When Truly Stuck

Strip to the minimal loop for one week: one course, Session Protocol only, logs on. Whatever still fails with everything else removed names the file to open next.
