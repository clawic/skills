# Techniques — What Works, When, and What to Retire

Technique choice is triage, not taste. Utility ratings below follow Dunlosky's technique review; the student's confirmed preferences in memory.md refine within these bounds, never against the high/low boundary.

## Utility Map

| Technique | Utility (Dunlosky) | Verdict |
|---|---|---|
| Practice testing | High | The backbone of every session (SKILL.md Rule 1) |
| Distributed practice | High | The schedule itself (Rule 2) |
| Interleaved practice | Moderate | After acquisition only (Rule 4); strongest in problem subjects |
| Self-explanation | Moderate | Pair with worked examples (`problem-subjects.md`) |
| Elaborative interrogation | Moderate | "Why would this be true?" for fact lists with underlying structure |
| Summarization | Low | One pass max; output = question list (Rule 7) |
| Highlighting | Low | Marks targets for later question-writing; never a study act itself |
| Rereading | Low | Pre-processing only (Rule 7) |
| Keyword mnemonic | Low for durability | Arbitrary mappings only; still needs retrieval reps (`memorization.md`) |
| Imagery for text | Low | Free to use while reading; never a session plan |

## Running the High-Utility Core

- **Blank-page dump**: everything remembered about a topic, book closed, then check against source. Cheapest full-coverage self-test; opens every session (Session Protocol 1).
- **Question generation**: 2-5 per section, three types — definition, why/how, applied case (Session Protocol 2). A section that yields no applied-case question is a section the student can't use yet.
- **Closed-book explanation (Feynman)**: pick concept → explain on paper as if to a novice → mark every stall and vague word → return to source only for the marked gaps. The stall IS the data; an explanation with no stalls on the first try means the concept was already known or the standard was too soft.
- **Self-explanation on worked examples**: after each step, state why this step; "because the book did it" = prerequisite gap, log it.
- **Elaborative interrogation**: convert flat facts into "why does X hold for Y but not Z". Works when the student has partial background; below that it produces confident confabulation — use worked examples first.
- Retrieval practice beat even elaborate open-book methods like concept mapping on delayed tests, including inference questions (Karpicke and Blunt) — "testing only checks learning" is backwards; testing IS the learning event.

## Named Systems, Mapped Honestly

- **Cornell notes**: the value is the cue column — built-in retrieval prompts. A Cornell page never quizzed from its cues is formatting theater (`essays-and-reading.md`).
- **Mind maps**: an organization pass for conceptual courses AFTER retrieval. Drawing the map open-book is summarization (low utility); reconstructing it closed-book is a test (high).
- **SQ3R and cousins**: keep the Question and Recite steps, drop the ritual around them — they are question generation and retrieval wearing a brand name.
- **Pomodoro**: an entry device for aversive starts, not a learning technique (`focus.md`).

## Learning Styles

- Matching teaching to a visual/auditory/kinesthetic "style" has no supporting evidence (Pashler's review). Match format to the MATERIAL — diagrams for anatomy, timelines for history, problems for math — and to what the exam demands.
- Preferences recorded in memory.md are engagement facts, not styles: honor "videos before reading" because this student demonstrably sticks with it, and still convert every format into retrieval (Rule 1 applies to video exactly as to text).

## Group Study

- Works as: every member solves or recalls solo FIRST, then the group compares and explains disagreements — explaining an error out loud is retrieval plus self-explanation.
- Fails as: shared rereading, or one member explaining while others nod — the explainer gets the practice, the nodders get exposure.
- Predicted-question brainstorms before exams are the other legitimate group use (`essays-and-reading.md`).
- Default: solo acquisition, group only for comparison rounds; a student's "no group study" in memory.md → Never is honored without argument.
