# Stalled Progress — Symptom to Cause

When teaching stops working, diagnose before adjusting. Each chain is ordered by probability; every step is a check, not a guess.

## The Universal First Three

1. Compare the last two checks against the 70-90% band (SKILL.md Rule 4) — above it: too easy; below it: overshooting. The band is the first differential.
2. Re-read your last two exchanges and count new named concepts — a breach of the 3-5 cap (Rule 2) explains most sudden silence.
3. Probe one prerequisite below the current topic — a missing prerequisite mimics every other failure mode.

## Same Question Re-Asked

1. Format failure by default (Rule 6): move one rung — plain prose → concrete example → analogy → table or diagram → worked problem.
2. Second re-ask after a rung change: prerequisite gap, not format — probe one level down and teach the gap first.
3. Third re-ask: the concept is compound — split it and teach the halves separately, each with its own check.

## Silence / Minimal Replies

Boredom and overload look identical from the outside (Rule 1). Run the differential:

1. Ask one quick application question at the current level.
2. Instant correct → bored: jump a tier, compress coverage.
3. Wrong or blank → overloaded: shrink the step, add a worked example.
4. Correct but slow, no engagement → not a difficulty problem: `learner-states.md` (fatigue, motivation).

## "Gets It in Session, Gone Next Session"

1. Were the checks immediate-only? Immediate success predicts nothing (SKILL.md Traps) — weight session-close and next-open checks instead.
2. Was the gap longer than 10-20% of the retention horizon (Cepeda)? Tighten the schedule (`retention.md`).
3. Recall fails but recognition works ("oh right, THAT") → it was stored but never practiced as retrieval: more generation, less presentation.
4. One concept keeps dying while its neighbors stick → interference or a misconception: find what it is confusable with and interleave the pair deliberately (`retention.md`), or check `misconceptions.md`.

## Can Define, Can't Apply

1. The intermediate profile (SKILL.md Diagnostic Probes): vocabulary without schema. Switch to problem-first.
2. Taught abstract-first? Rebuild with concreteness fading (`formats.md`).
3. Applies only to cases matching the taught example's surface → example variability was too low: add far-surface examples (`formats.md`).

## Confidently Wrong, Repeatedly

Same error class across different-surface problems is a wrong model, not a gap → `misconceptions.md`. Drilling harder automates the wrong model.

## Plateau (band stuck for weeks)

1. Checks recycle familiar surface forms → the learner retrieves your questions, not the concept (`questions.md` Anti-Gaming).
2. Difficulty raised by obscurity or trick phrasing instead of transfer distance → recalibrate (`questions.md`).
3. Scaffolds never removed → expertise reversal (Rule 7): the worked examples are now the ceiling; go problem-first.
4. All of the above clean → consolidate: two sessions of pure review and application, no new content, then reassess.

## Learner Pushes Back on the Method

- "Just give me the answer": urgency context — answer now, log the topic for teaching later. One urgent bypass is context, not preference; the same request in calm conditions twice is a preference (Rule 8).
- "Stop quizzing me": keep the generation requirement, change its costume — predictions and "how would you handle X" read as conversation, not tests (`questions.md`).
- Open dislike of a format that is demonstrably working: record the preference (2-signal rule) but the ceiling holds — preferences pick the entry rung, never override the band (SKILL.md Preference Memory).
