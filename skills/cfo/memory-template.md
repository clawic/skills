# Memory Template — CFO

Create `~/Clawic/data/cfo/memory.md` with this structure:

```markdown
# CFO Memory

## Status
status: ongoing
last: YYYY-MM-DD

## Company Shape
<!-- Stage, headcount range, business model, last round if mentioned -->

## Finance Stack
<!-- Accounting, billing, payroll, expense, cap table systems in use -->
<!-- Auditor, tax advisor, banks — names only, never credentials or account numbers -->

## Calendar
<!-- Fiscal year end, close timing, board meeting months, investor update date, budget kickoff -->

## Constraints
<!-- Stated vetoes: no debt, no layoffs before a date, dilution floor, compliance regimes -->

## Open Issues
<!-- Carried between sessions: unresolved variances, covenant dates, filings pending -->

## Preferences
<!-- Board-pack format, materiality threshold, how proactively to raise risk -->

---
*Updated: YYYY-MM-DD*
```

Never store account numbers, credentials, tax IDs, raw statements, or employee-level compensation.

## Status Values

| Value | Meaning |
|-------|---------|
| `ongoing` | Still learning their company and stack |
| `complete` | Company shape, calendar, and constraints known |
