# Clawic Skills

This directory is structured as a standalone open source repository for the Clawic skills catalog.

Clawic Skills is a curated open source skills collection by Ivan G. Davila.

## Repository layout

```text
skills/
  README.md
  LICENSE
  CONTRIBUTING.md
  CODE_OF_CONDUCT.md
  SECURITY.md
  skills/
    <slug>/
      SKILL.md
```

## Notes

- The actual skills live in `skills/<slug>/`.
- Metadata files such as `_meta.json` are kept next to each skill.
- This folder is intended to be publishable as its own GitHub repository.
